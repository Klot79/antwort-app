# Antwort! v8 – Materialimport + fester Display-QR

- Administrator: manuelle Fragen, Text → Fragen, PDF/Bild → OCR → Fragen-Vorschläge → Prüfen → „Fragen übernehmen“.
- Fragenliste: keine Start-/Display-Schaltfläche pro Frage; ein zentraler „🎮 Spiel starten“-Button.
- Lehrer-Spielmodus: MacBook zeigt Frage und Live-Ergebnisse.
- AirPlay-Display: Frage + A/B/C/D; unten links fester QR-Code. iPhone scannt diesen QR-Code und verbindet automatisch.
- Fester Scanner-Raum: K7P3Q.
- Für PDF: pdf.js; für Bild/gescannte PDF-Seiten: Tesseract.js.
- PeerJS benötigt Internet; Kamera auf iPhone benötigt HTTPS (z. B. GitHub Pages).
